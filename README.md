# Лабораторная работа 1 — вариант 11

Учебный прототип: стек на основе собственной очереди.
Это промежуточная версия, а не вся лабораторная работа.

## Что работает

- Абстрактный класс Queue с динамическим кольцевым массивом double.
- Класс Stack, который использует операции очереди.
- Добавление числа, извлечение и просмотр вершины, вывод стека.
- Автоматическое увеличение массива, когда в нём заканчивается место.
- Конструкторы, глубокое копирование, присваивание и освобождение памяти.
- Сообщения конструкторов и деструкторов, обработка неверного ввода.

Наследники List и Deque, класс Keeper и файловые операции в этот прототип не входят.
Контейнеры STL и std::string не используются.

## Файлы

- src/Queue.h — объявление абстрактной очереди.
- src/Queue.cpp — память, базовые операции и вывод.
- src/Stack.h — объявление стека.
- src/Stack.cpp — push, pop и top на основе очереди.
- src/main.cpp — ввод и меню.
- build.bat — сборка в Windows.
- .gitignore — исключение скомпилированных и временных файлов из Git.

## Как собрать и запустить

Нужен g++ с поддержкой C++17. На этом компьютере он установлен в C:\msys64\mingw64\bin.
Открой PowerShell в папке проекта и выполни:

```powershell
.\build.bat
.\lab1.exe
```

Или вручную при доступном g++:

```powershell
g++ -std=c++17 -Wall -Wextra -Wpedantic src/Queue.cpp src/Stack.cpp src/main.cpp -o lab1.exe
.\lab1.exe
```

Вместимость вводится при запуске. Дробные числа нужно вводить через точку.
В отображении [10, 20, 30] вершина стека — 30.

## Как работает pop

Очередь удаляет первое число, а стек должен удалять последнее.
Для [10, 20, 30] переносим 10 из начала в конец: [20, 30, 10].
Потом переносим 20: [30, 10, 20]. Теперь извлекаем начало — 30.
Остальные числа остаются в правильном порядке: [10, 20].

## Что понять перед следующим этапом

- FIFO у очереди и LIFO у стека.
- Что означают data, capacity, front и count.
- Почему индекс вычисляется как (front + i) % capacity.
- Почему для копии нужен отдельный массив.
- Зачем деструктор Queue виртуальный.
- Почему pop работает за O(n), а top — за O(1).

Начни чтение с Queue.h, затем Queue.cpp, Stack.h, Stack.cpp и main.cpp.
В Queue заранее есть get/set и clone: это пригодится для следующих частей лабораторной.
Методы clone возвращают новую независимую копию; вызвавший их код обязан её удалить.
